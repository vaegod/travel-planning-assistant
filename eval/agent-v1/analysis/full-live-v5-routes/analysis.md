## 修复方向

1. 工具参数直接使用 JSON 对象，兼容旧字符串输入；保留严格解析，并返回具体字段路径或行列位置，避免重复提交同一格式错误。
2. 明确酒店休息的 rest=true 和分钟数范围；将结构、字段、分钟数问题一次性反馈，先修草稿再发地图请求。
3. 地图请求失败在 13 条中出现。通用 IOException 文案不足以认定是高德故障或连接复用问题；用本地断连测试验证有限重连，失败仍明确交付服务错误。
4. 由后端按草稿集中查询相邻路线；模型收到 valid=true 即停止，不额外逐条调用路线工具。缩短模型反馈，保留任务内查询缓存。
5. 正式复测保持模型、数据、独立评分器、任务协议、轮数上限及节流配置一致；80 个尝试全部重新运行，基础设施失败照常计入。

本轮使用过的 40 条属于回归集，不是新盲测。真实高德服务准确性不在离线合成路线评测范围内。
